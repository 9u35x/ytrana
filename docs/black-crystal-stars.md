# نجوم الكريستال السوداء في Ytrana

تظهر بطاقة النجوم في الملف الشخصي على الويب والهاتف، مع معاينة تفاعلية للمستويات 1–10، شارات ملونة وبلورة بنفسجية للمستوى العاشر **نجمة الكريستال السوداء (Black Crystal Star)**. المستوى الفعلي يبقى ظاهرًا عند استعراض مستوى مقفل؛ المعاينة لا تمنحه للحساب.

## كيف تُكتسب النجوم؟

المصدر الوحيد هو بيانات الخادم، وليس قيم العرض في الجهاز. المستوى الأول نقطة البداية للجميع. المستويات الأعلى تحتاج **المتابعين وأيام النشر معًا**، دون شراء أو نقاط مدفوعة، ودون تعديل خطط الاشتراك الثلاث أو إضافة دفع.

| المستوى | الاسم | المتابعون المطلوبون | أيام النشر المطلوبة |
|---:|---|---:|---:|
| 1 | نجمة البداية | 0 | 0 |
| 2 | النجمة الصفراء | 100,000 | 1 |
| 3 | النجمة الفضية | 500,000 | 3 |
| 4 | النجمة الذهبية | 1,000,000 | 7 |
| 5 | نجمة الياقوت | 2,500,000 | 14 |
| 6 | نجمة الزمرد | 5,000,000 | 30 |
| 7 | النجمة الماسية الزرقاء | 10,000,000 | 60 |
| 8 | النجمة الأرجوانية | 20,000,000 | 90 |
| 9 | النجمة الكريستالية | 35,000,000 | 180 |
| 10 | Black Crystal Star | 50,000,000 | 365 |

هذه عتبات منتج مستوحاة من المرجع، وليست أعداد حسابات أو إحصاءات إنتاج. أيام النشر شرط نشاط إضافي مقصود. المتابعون محسوبون من علاقات `Follower` المقبولة فقط؛ تُستبعد الطلبات المعلقة، متابعة النفس، والحسابات غير النشطة أو المحظورة أو المجمّدة حاليًا، بما فيها التجميد غير المحدد المدة. لا يُدّعى وجود تحقق كامل من المتابعين الوهميين.

يُحسب يوم UTC مرة واحدة مهما تعددت المنشورات ومقاطع Reels فيه. لا تُحسب المنشورات المؤرشفة أو المحذوفة، ولا المحتوى المرتبط بالدوائر أو صفحات الأعمال، ولا الطوابع المستقبلية. يجري اتحاد الأيام وعدّها في SQL بدل تحميل جميع السجلات إلى الذاكرة. أرقام النشاط ليست سجل دخول أو حالة اتصال، ولا تكشف نشاط الدوائر الخاصة. محتوى الحساب المقيّد لا يُكشف لغير المصرح لهم.

المستوى والتقدم يعاد حسابهما عند القراءة: إزالة متابعة مؤهلة، حذف المحتوى أو أرشفته قد يخفض التقدم أو المستوى. تقدم المستوى التالي هو أصغر نسبة من نسبتي استيفاء المتابعين والأيام، محصور بين 0 و100؛ المستوى العاشر يعيد 100. معاينة المستوى تعرض متطلباته وتقدم الحساب إليها منفصلًا عن المستوى المكتسب.

## ماذا تعني المكافأة؟

**لا توجد مكافأة وصول أو انتشار مطبقة حاليًا.** الخلاصات القائمة زمنية، ولم يتغير ترتيبها. نسب 5%–50% المعروضة هي تصور معلن وغير مفعّل لأولوية توصية مستقبلية، وليست زيادة مضمونة في المشاهدات أو الوصول. لا توجد رسوم أو خدمة خارجية جديدة.

## عقد الخادم والخصوصية

`GET /api/users/{username}/stars`

يعيد `level`, `name`, `followers_count`, `active_days`, `progress_percent`, `next_level`، و`reward` الذي يحتوي دائمًا `applied: false`، إضافة إلى `proposed_priority_bonus_percent` والوصف الصريح. يعيد `levels` عشرة عناصر تحتوي `level`, `name`, `required_followers`, `required_active_days`, `color`, `icon`, `earned`, `proposed_priority_bonus_percent`. الرمز نجمة للمستويات 1–9 وبلورة للمستوى 10.

الحساب غير الموجود أو غير النشط أو المحظور أو المجمّد يعيد `404`. كذلك يُرفض غير المصرّح له وفق سياسة عرض محتوى الحساب نفسها؛ لا يصبح مسار النجوم قناة لتجاوز خصوصية الحساب. لا يعيد المسار بيانات دخول أو بريدًا أو أرقام متابعين فردية. لا يحتاج النظام جدولًا جديدًا أو ترحيلًا مدمّرًا.

الواجهات تعالج التحميل والفشل وإعادة المحاولة وسباقات الطلبات. لا يعاد استخدام بيانات الحساب السابق عند تبديل الهوية أو فقدان الإذن. تغييرات المصدر لا تحدّث التطبيق المثبت أو الموقع الحي تلقائيًا؛ لم يحدث نشر إنتاجي أو بناء حزمة إصدار جديدة في هذه الخطوة.

## الاختبارات

من جذر المستودع:

```sh
pip install -r requirements-test.txt
PYTHONPATH=backend:tests python -m pytest tests -q
for f in tests/*.cjs mobile/tests/*.cjs; do node "$f" || exit; done
cd mobile && npm ci && npm run typecheck
```

اختبارات الحدود الكبيرة تختبر دالة الأهلية مباشرة، ولا تزرع ملايين المتابعين. اختبارات قاعدة البيانات وHTTP تستخدم قاعدة مؤقتة، لا الإنتاج. اختبارات واجهات العملاء تتحقق من اختيار المستويات، سلامة النصوص، الصفر والحد الأقصى، حالات الفشل والطلبات المتأخرة؛ فحص الهاتف الآلي لا يغني عن تجربة Android وiPhone فعليين قبل إصدار لاحق.
